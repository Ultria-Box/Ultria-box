# Code of Conduct

## Scope

This project is intended for security education, authorized penetration testing
and defensive research. It must never be used against a system without the
owner's explicit written permission.

## Required conduct

- Test only systems you own or for which you hold written authorization.
- Keep a record of the scope and the authorization for every engagement.
- Handle collected data as confidential and delete it when the engagement ends.
- Respect applicable laws and privacy regulations (GDPR and local equivalents).
- Report findings responsibly to the affected owner.

## Prohibited

- Unauthorized access, credential theft or fraud.
- Publishing data obtained from a third party without consent.
- Using this project to harass, extort or cause damage.

## Enforcement

Any misuse is outside the scope of this project and is not supported by its
authors. Reports of abuse can be opened as issues on the repository.
